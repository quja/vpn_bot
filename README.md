# VPN Bot — Telegram-бот для продажи VPN-подписок

Telegram-бот с полным циклом продажи VPN-доступа: подписки, приём платежей,
автоматическая выдача и продление доступа через API VPN-панели, реферальная
программа и админ-функции. Написан на асинхронном Python (aiogram 3).

> Личный проект (pet-project), разработан в подходе AI-assisted development.
> Демонстрирует работу с платёжными системами, внешними API, базой данных
> и фоновыми задачами в асинхронной среде.

## Возможности

- **Подписки и тарифы:** покупка и продление VPN-доступа, пробный период,
  несколько тарифных слотов, лимиты трафика с ежемесячным сбросом.
- **Приём платежей:** интеграция с ЮKassa (создание платежа, проверка статуса,
  фоновый монитор оплат, автоматическая выдача доступа после оплаты).
- **Управление VPN:** интеграция с API панели Remnawave — создание и продление
  ключей доступа, контроль трафика, уведомления об окончании подписки.
- **Реферальная программа:** партнёрские проценты, бонусы за приглашённых,
  реферальные ссылки.
- **Промокоды:** одноразовые и многоразовые, скидки, промо на пробный период.
- **Админ-функции:** просмотр пользователей, ручное управление доступом.
- **Защита:** антифлуд-middleware (ограничение частоты запросов на пользователя).

## Стек

- **Python 3**, **aiogram 3** (async, роутеры, FSM, middleware)
- **aiosqlite** — асинхронная работа с SQLite
- **ЮKassa SDK** — платежи
- **Remnawave API** (httpx) — управление VPN-панелью
- python-dotenv — конфигурация через переменные окружения

## Архитектура

```
app/
├── main.py          — точка входа, инициализация бота и фоновых мониторов
├── config.py        — настройки из .env (тарифы, токены, лимиты)
├── handlers.py      — обработчики команд и колбэков, бизнес-логика
├── payments.py      — интеграция с ЮKassa
├── remnawave_api.py — клиент API VPN-панели
├── db.py            — слой доступа к базе (aiosqlite)
├── keyboards.py     — инлайн-клавиатуры
└── antiflood.py     — middleware защиты от флуда
```

Три фоновых монитора работают параллельно с ботом: проверка оплат,
контроль трафика/подписок и уведомления об окончании доступа.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # заполнить своими значениями
python -m app.main
```

Все секреты (токен бота, ключи ЮKassa, токен Remnawave) задаются в `.env` —
в коде их нет. Пример переменных — в `.env.example`.

## Что можно развить

- Перенос хранилища FSM с памяти на Redis для масштабирования.
- Покрытие бизнес-логики тестами.
- Веб-панель статистики для админа.
